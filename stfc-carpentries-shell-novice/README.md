# Lesson data

Data files used in the STFC Carpentries shell-novice lessons.

## Contents

- `exercise-data/` — files for the lesson exercises:
    - `alkanes/` — structure files for several molecules (`.pdb`)
    - `animal-counts/` — survey counts in CSV format (`animals.csv`)
    - `creatures/` — classification records for mythical creatures (`.dat`)
    - `writing/` — text files used for searching (`haiku.txt`, `LittleWomen.txt`)
    - `numbers.txt` — a list of numbers
- `north-pacific-gyre/` — data from Jovyan Jetty's survey, used in the Jovyan pipeline story
